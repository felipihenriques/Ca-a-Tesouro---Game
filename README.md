# 🏴‍☠️ Ilha do Tesouro — Jogo em Python

## 📖 Sobre o projeto

O **Ilha do Tesouro** é um jogo interativo desenvolvido em Python, no qual o jogador precisa tomar decisões para encontrar um tesouro escondido.

Durante a aventura, o jogador enfrenta diferentes desafios, e cada escolha pode determinar sua vitória ou derrota.

Este projeto foi desenvolvido como parte dos meus estudos em programação, com o objetivo de praticar conceitos fundamentais da linguagem Python.

## 🚀 Tecnologias utilizadas

- Python 3
- Estruturas condicionais (`if`, `elif`, `else`)
- Entrada de dados com `input()`
- Conversão de tipos com `int()`
- Saída de dados com `print()`
- Strings de múltiplas linhas
- Operadores de comparação

## 🎮 Como jogar

O jogador começa sua aventura em busca de um tesouro e precisa superar três desafios:

**1. Escolher um caminho**

- Esquerda: continua a aventura.
- Direita: cai em um buraco e perde o jogo.

**2. Atravessar o lago**

- Nadar: é atacado por uma truta.
- Esperar: consegue avançar para a próxima fase.

**3. Escolher uma porta**

- 🔴 Vermelha: queimado pelo fogo.
- 🔵 Azul: devorado por feras.
- 🟡 Amarela: encontra o tesouro e vence!

## 💻 Como executar o projeto

**1.** Instale o Python 3 em seu computador.

**2.** Baixe ou clone este repositório.

**3.** Abra o terminal na pasta do projeto.

**4.** Execute o comando:

```bash
python ilha_do_tesouro.py
```

**5.** Digite os números correspondentes às opções apresentadas e tente encontrar o tesouro.
